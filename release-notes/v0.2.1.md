# anaf-sync 0.2.1 — tray fixes

Corecții pentru aplicația din bara de sistem. / Bug-fix release for the desktop tray companion.

## Fixes

- **Tray menu header no longer clips its subline.** `QMenu` caches one rect per action and never sees a label's text change, so once the header had been measured at a short subline ("chiar acum"), a longer one ("acum 19 minute · 10 facturi noi") was painted into that one-line rect — clipped at the bottom and overlapping the headline. Reopening the menu did not heal it, which made it look intermittent.
- **Setări can be resized properly on Windows.** The save bar sits outside the form's scroll area, so its width is a hard floor on the whole window. Its note was a label that refused to shrink below its full sentence, putting that floor at 1204px on Windows fonts — past the window's own 1200px maximum. The note now elides, and the window's minimum width is derived from what the form actually measures on the running platform instead of a hard-coded 760px.
- **Setări no longer scrolls sideways** when the variable reference is expanded at the minimum window width (#1).

## Internal

- The Windows CI gates now actually gate: the multi-command `Gates` step ran under PowerShell, which only propagates the *last* exit code, so pytest, ruff and black failures were silently discarded and mypy alone decided the bundle.
- `release.yml` installs the `tray` extra before running mypy, matching `ci.yml`'s Linux leg.

> ⚠️ **The bundles are unsigned** — no macOS notarization, no Windows Authenticode. First run triggers the usual OS warning; use the right-click-open workaround documented in the README.
