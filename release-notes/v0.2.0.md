# anaf-sync 0.2.0 — the desktop tray companion

## What's new since v0.1.4

- **Desktop tray companion** — a PySide6 menu-bar/system-tray app alongside the CLI, built across M0–M4: core enablers, live status indicator, the **Facturi** window over the archive catalog, and the **Setări** config editor (tomlkit round-trip with live preview).
- **Facturi and Setări are separate windows**, with Romanian date formatting and resizable columns.
- **Template variable reference panel** in Setări; the path context is narrowed to the 15 variables that actually render.
- **Autostart and standalone bundles** — PyInstaller specs for a menu-bar-only macOS `.app`, a windowed Windows exe, and a Linux one-dir binary, built per-OS by the new `release-tray` workflow.
- Dependency floor raised to **anafpy 0.5.1** for readable contact e-mails.

> ⚠️ **The bundles are unsigned** — no macOS notarization, no Windows Authenticode. First run triggers the usual OS warning; use the right-click-open workaround documented in the README. Signing is follow-up work before these are recommended for wide distribution. The CLI on PyPI (`pip install anaf-sync`) is unaffected.

**Known issue:** on Windows, expanding the variable reference in Setări at the minimum window width gives the form a horizontal scrollbar (#1). Cosmetic.
