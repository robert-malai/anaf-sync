# anaf-sync 0.2.3 — the README matches the login you actually run

Documentation release: no code changes — the CLI and the tray are untouched
from [v0.2.2](https://github.com/robert-malai/anaf-sync/releases/tag/v0.2.2).

## Docs

**The README's authentication walkthrough describes anafpy 0.5.1's login.**
`anafpy auth login` now serves the OAuth callback itself, with a throwaway
certificate generated on the spot — the browser shows exactly one expected
"connection is not private" warning to click through, and the flow finishes on
its own. The README had still been leading with the workarounds that were
necessary before that: `--paste` and a hand-made mkcert certificate are now
documented as the alternatives they became.

The Romanian was tightened in the same pass — the certificate wording settled
on the plain term, "design rationale" left untranslated, and a few literalisms
fixed (dosar/folder, combinați).
