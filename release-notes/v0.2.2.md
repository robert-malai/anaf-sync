# anaf-sync 0.2.2 — smaller, more truthful internals

Cleanup release: no new features, smaller and more truthful internals.

- Removed the never-wired health enrichment (interval/partner plumbing); the tray's amber alert now shows the purge countdown it always actually had.
- One shared 5-day delay rule (`health.is_delayed`), one message projection in the engine, shared script-resolution between scheduler and autostart.
- Facturi no longer re-scans the archive on every footer refresh.
- `anaf-sync status` opens the archive read-only and no longer creates state as a side effect.
- Removed the redundant `anaf-sync version` subcommand — use `anaf-sync --version`.
- Documentation synced with the shipped tray (DESIGN.md, CLAUDE.md, CONTRIBUTING.md, README.md).
