# anaf-sync 0.1.1 — cyclopts CLI, native logging, Romanian docs

## What's new since v0.1.0

- **CLI migrated from typer to cyclopts**, matching anafpy.
- **Scheduled runs log to the native OS facilities** — Windows Event Log, macOS os_log, systemd journal — with automatic console/system mode detection.
- **Romanian month template variables** (`issue_month`, `created_month`) and case conversions for path templates.
- **`SyncState` persists inside its mutators** — atomic durability is now the state class's contract, not the callers'.
- **Opt-in live integration suite** against the real ANAF endpoints (read-only; `ANAFPY_LIVE=1 uv run pytest -m live`).
- **README rewritten in Romanian** for the operator audience; developer docs split into CONTRIBUTING.md.
- Dependency floor raised to **anafpy 0.4.1**.
